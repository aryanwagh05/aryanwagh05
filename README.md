# Aryan Wagh

I build AI and full-stack products with a production mindset: traces, evals, RAG debugging, cost and latency visibility, typed APIs, clean interfaces, and systems that are actually useful after the demo.

## Current Focus

- LLM observability: trace/span data models, prompt/version regression, cost and latency monitoring.
- AI reliability: groundedness, citation support, schema validity, tool-call correctness, and eval gates.
- Full-stack product engineering: Next.js, React, TypeScript, Python, Postgres, Supabase, and deployment-ready dashboards.
- Portfolio projects that show real engineering signal instead of generic prompt wrappers.
